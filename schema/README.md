# Description

La carte électronique permet de connecter les capteurs et le servomoteur au STM32f746. 
La carte peut ainsi être pluger grâce aux pin ajoutés sur le STM32. 


---


# Choix des composants 

Un régulateur 7805 a été choisi afin d'avoir une tension de 5V stable, quelque soit la tension d'alimentation. Les condensateurs sont présents sur indication de la fiche technique du régulateur. 
Les résistances sont présentes pour les capteurs infrarouge comme résistance de pull up.
